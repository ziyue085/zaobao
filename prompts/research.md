# 发现候选（researcher 角色）

目标：在过去 24 小时内，为 `config/watchlist.yaml` 里每个栏目找出**可能的**新事实。

这一步只负责"找出线索"，不负责判定能不能发。发现的条数通常远多于最终发出的条数。

## 一、先定窗口

```
窗口起点 = 当前时间 - watchlist.yaml: meta.window_hours（默认 24 小时）
窗口终点 = 当前时间
```

把起止时刻写进最终输出的「统计窗口」一行。**每一次判断时间都要回到这两个刻度**，不要凭"感觉是新的"。

## 二、按栏目逐一发现

### 普适性政策

按 `watchlist.yaml: sections.universal_policy.focus` 的关键词逐一检索。

- 优先直接访问政府与监管机构官网的最新发布栏目（见 `config/sources.yaml` 的 `primary`）。
- 中国人民银行：公开市场业务交易公告、货币政策工具、新闻发布。
- 财政与税收：财政部与税务总局的新文件、公告。
- 金融监管：金融监管总局、证监会的规章与处罚。
- 社保／医保／养老／就业：人社部、国家医保局。
- 教育／人口／重大产业政策：教育部、国家统计局、发改委。

**地方普通政策不收录**，除非具有明显全国意义或公共价值（例如成为全国性试点、被中央文件明确推广）。

### 投资

分两路走，不要混：

1. **机构与政策**：美联储（议息声明、会议纪要、官员讲话原文）、中国人民银行（公开市场操作、利率工具）、国务院国资委、大型央企与重要国企的公告。
2. **固定关注对象**：`sections.investment.assets` 列出的对象逐个查。

行情与公告必须用专项工具拿，不要用搜索摘要。要抓的事实类型：

财报、业绩预告、公司公告、股权变化、回购、增减持、并购重组、重大合同、管理层变化、监管措施、产能、产品、行业数据、猪价与生猪产能、指数重大调整、美联储会议与政策、人民银行重要操作。

**只要固定关注对象当天只有正常价格波动、没有公告与异常事件，就不要把它写成条目。** 关注 ≠ 必须写。

### AI

盯 `sections.ai.orgs` 的官方渠道：官网博客、发布页、GitHub 仓库、模型卡与 API 文档、arXiv。

值得找的：AI 政策、新模型、推理模型、多模态、Agent、AI 编程、AI 搜索、AI 视频、AI 终端、AI 手机、AI PC、智能眼镜、机器人、重要开源项目、API 价格变化、上下文变化、模型能力实质升级。

直接过滤掉：普通融资、没有技术内容的宣传稿、普通版本更新、纯预告、单纯榜单、炒作性质信息。

### 社会热点

按 `sections.social.allowed` 检索：公共安全、食品、医疗、教育、交通、重大社会事件、全国性高关注事件、有公共价值的热点。

娱乐或名人八卦**只在同时满足三条时才候选**：热度足够高、基本事实已经核实、不把传闻写成事实。

> **「上热搜」本身不等于值得收录。** 热搜是发现的入口，不是证据。

### 人物与思想信号

找有信息量的**新内容**，不是人物动态。

来源类型：论文、演讲、长访谈、技术文章、播客、公开信、深度文章。
人物类型：企业家、科学家、AI 研究者、投资者、技术专家、经济学者、其他真正有新观点的人。

每条必须能提炼出至少一项：新观点／新数据／新方法／新判断／新技术细节。

普通鸡汤、重复观点、宣传稿直接丢。

### 意外但重要

先按前面的栏目正常检索，**顺手记录**那些不属于用户长期关注、但确实重要的东西。

门槛必须明显高于普通新闻。参考类型：可能成为重大历史事件、显著科技突破、重大国际经济或金融事件、重大公共安全事件、极重要的新制度、异常重要的数据或现象。

每天最多 3 条。宁缺毋滥，一条都没有很正常。

## 三、每条候选必须留下什么

在进入核验之前，每条候选至少要有：

- 一句能直接表达事实的标题草稿
- entity（主体）／action（核心动作）／object（核心事件）
- 原始事件时间
- 至少一个能引用的 URL
- 来源层级初判：primary / trusted_secondary / discovery_only

entity / action / object 三项直接决定后续去重，写的时候就要用**归一化后的写法**（见 `references/dedup.md`）。

## 四、常见错误

| 错误 | 后果 |
|---|---|
| 把搜索结果摘要当成候选的事实依据 | 后面整条都不可信 |
| 只找到聚合页或搜索页 URL | 来源判不出一手，等于没找到 |
| 事件时间用"报道时间"而不是"事件发生时间" | 时间窗判断全错 |
| 顺手把没核实的传闻也建了候选 | 后面要花时间清理，且容易漏 |
| 因为关注列表里有某只股票就硬找一条 | 直接被 LOW_VALUE 拦下 |
